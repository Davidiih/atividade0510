## Resumo dos Conceitos Praticados

Durante a atividade pratiquei HTML através do curso Cat Photo App do freeCodeCamp.

Aprendi a utilizar títulos, parágrafos, listas ordenadas e não ordenadas, links, imagens e elementos semânticos do HTML.

As principais dificuldades foram compreender a estrutura das tags e a organização do conteúdo da página. Os elementos mais utilizados foram `<h1>`, `<h2>`, `<p>`, `<img>`, `<ul>`, `<ol>` e `<a>`.
